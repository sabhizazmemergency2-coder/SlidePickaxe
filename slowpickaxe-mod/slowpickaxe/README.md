# 🪨 Slow Pickaxe Animation

Mod Fabric 1.21.1 qui ralentit l'animation de swing de la pioche.

## Configuration

Ouvre **ModMenu** → *Slow Pickaxe Animation* pour régler le multiplicateur de lenteur (1 = normal, 10 = très lent).

## Dépendances

- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Cloth Config](https://modrinth.com/mod/cloth-config)
- [ModMenu](https://modrinth.com/mod/modmenu)

## Compiler soi-même

```bash
./gradlew build
```

Le `.jar` se trouve dans `build/libs/`.

## Télécharger le .jar

Va dans l'onglet **Actions** → dernier build → **Artifacts** → `slowpickaxe-mod`.
